# ChEMBL Glucagon-like peptide 1 receptor (GLP-1) Bioactivity dataset

An exploratory data analysis (EDA) of the bioactivites reported in the ChEMBL database for the Glucagon-like peptide 1 receptor (GLP-1) target.

## Project Overview

This repository contains a Jupyter Notebook analyzing an extract of the ChEMBL database covering all reported bioactivities for the GLP-1 taget. This target is associated with the GLP-1 class of blockbuster weight-loss drugs.

## Data Source

EBI-ChEMBL database - Target CHEMBL1784
https://www.ebi.ac.uk/chembl/
